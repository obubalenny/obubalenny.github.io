## 🛡️ Project 1: ElimuTrek – School Management System
* **Core Focus:** Relational Database Integrity & Secure Backend Architecture

### 📑 Problem Statement
Educational institutions require robust, reliable administration environments. Disorganized storage of academic records poses major data collision risks, lacks atomic entry verification, and exposes sensitive student information to unauthorized modification.

### 🛠️ Approach & Tools Used
* **Tools:** Python, PostgreSQL, Git, GitHub.
* **Methodology:** Designed a fully normalized relational database schema mapping student identities, courses, and administration tables. I wrote custom Python input validation scripts to handle raw user inputs safely before executing database queries to ensure robust data control.

### 📸 Screenshots & Documentation
*📁 Code repository and deployment workflows can be reviewed on my official [ElimuTrek GitHub Project Repository](https://github.com).*

### 🔑 Key Lessons Learned
* Mastered relational database design constraints (Primary Keys, Foreign Keys) to maintain absolute data consistency.
* Realized the critical importance of parameter-checking to prevent processing logic failures within complex backend applications.
