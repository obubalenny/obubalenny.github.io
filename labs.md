## 🛡️ Project 1: ElimuTrek – School Management System
* **Core Focus:** Relational Database Integrity & Secure Backend Architecture

### 📑 Problem Statement
Educational institutions require robust, reliable administration environments. Disorganized storage of academic records poses major data collision risks, lacks atomic entry verification, and exposes sensitive student information to unauthorized modification.

### 🛠️ Approach & Tools Used
* **Tools:** Python, PostgreSQL, Git, GitHub.
* **Methodology:** Designed a fully normalized relational database schema mapping student identities, courses, and administration tables. I wrote custom Python input validation scripts to handle raw user inputs safely before executing database queries to ensure robust data control.

### 📸 Screenshots & Documentation
*📁 Code repository and deployment workflows can be reviewed on my official [ElimuTrek GitHub Project Repository](https://github.com).*

### 🔑 Key Lessons Learned
* Mastered relational database design constraints (Primary Keys, Foreign Keys) to maintain absolute data consistency.
* Realized the critical importance of parameter-checking to prevent processing logic failures within complex backend applications.

## 🔍 Lab 2: Network Traffic Analysis & System Triage
* **Core Focus:** Front-line Incident Isolation & Technical Diagnostics

### 📑 Problem Statement
During high-traffic operational windows in a public-facing service hub environment, identifying localized workstation network faults and basic endpoint configurations quickly is essential to maintaining institutional continuity and preventing service downtime.

### 🛠️ Approach & Tools Used
* **Tools:** System Diagnostic Utilities, Network Configuration Auditing, Hardware Isolation Protocols.
* **Methodology:** Applied technical troubleshooting matrices cultivated during my time at **Huduma Centre**. This involved systematic diagnostic staging—checking basic hardware connectivity loops, verifying local client protocol configurations, and accurately documenting high-priority anomalies for escalation paths.

### 🔑 Key Lessons Learned
* Learned how to isolate complex software environment failures into clear, modular troubleshooting steps.
* Developed an understanding of operational security priorities, user authorization challenges, and the impact of front-line technical resilience on broader infrastructure stability.
